## 1. Executive Summary
This report presents a passive acoustic monitoring pipeline for detecting and classifying eight Antarctic baleen whale vocalisation categories using a Convolutional Recurrent Neural Network (CRNN) and a Domain-Adversarial Neural Network (DANN).

The models were trained using Casey 2014 recordings, with unlabelled Greenwich 2015 recordings used for target-domain adaptation. A recording-level partition separated source training, source validation, target adaptation, target validation and held-out target testing, preventing recording overlap between these subsets.

On 57 held-out Greenwich 2015 recordings containing 387 reference events, the DANN model achieved a macro-F1 of 0.0203 compared with 0.0081 for the baseline CRNN. Paired recording-level bootstrap analysis over 2,000 resamples produced a mean macro-F1 difference of +0.0122, with an empirical 95% confidence interval of [+0.0075, +0.0174].

The improvement was primarily associated with Antarctic Blue Whale Bm.Ant-A detection, which increased from zero true positives for the baseline to 96 for DANN. This improvement came with a substantial false-alarm cost, increasing from 97.86 to 163.41 false positives per hour.

These findings demonstrate a measurable performance difference under the evaluated source-to-target adaptation protocol. They do not establish generalisation to independent geographic sites. The high false-positive burden, limited class coverage and absence of a controlled DANN ablation remain important limitations.

## 2. Methodology & System Design

### 2.1 Audio Preprocessing & Spectrogram Representation
To manage the sampling rate discrepancy between datasets (1000 Hz for Casey vs. 253 Hz for Greenwich) and resolve very low frequency structures (10 to 120 Hz) without aliasing:
1. **Dynamic Resampling**: All audio segments are resampled to a common $SR = 250$ Hz using high-performance `soxr` rational resampling. This aligns datasets to a single representation.
2. **High-Pass Filtering**: A 10 Hz 4th-order Butterworth high-pass filter is applied to remove low-frequency hydrostatic noise, shipping noise, and wave activity.
3. **Linear Spectrogram**: A Short-Time Fourier Transform (STFT) magnitude spectrogram is computed using `n_fft = 256` and `hop_length = 64`, corresponding to a 1.024-second analysis window ($256/250$), a 0.256-second frame hop ($64/250$), and approximately 0.98 Hz frequency-bin spacing ($250/256 \approx 0.977$ Hz). Linear frequency scaling is used to preserve high resolution across the fundamental frequencies of Antarctic whale calls.
4. **Label Grid Mapping**: Frame-level multi-hot ground truth label matrices of shape `(num_frames, 8)` are generated by converting local start/end sample offsets to time frame indexes relative to each 30-second clip.

### 2.2 Model Architecture: CRNN
The model utilizes a Convolutional Recurrent Neural Network (CRNN) to extract spatial-temporal spectrogram features and capture temporal sequence constraints:
*   **CNN Frontend**: Consists of 5 Conv2D layers (channel sequence: 16 $\to$ 32 $\to$ 64 $\to$ 128 $\to$ 256) with Batch Normalization and ReLU activations. Max-pooling is applied *only* along the frequency axis (`MaxPool2d(2, 1)`) to reduce frequency dimensions from 129 to 4 bins while keeping the time frame dimension constant at 118 frames.
*   **RNN Processor**: A 2-layer Bidirectional GRU (128 hidden units) processes the flattened frequency-channel sequence `(batch_size, 118, 1024)` to learn contextual temporal patterns of calls.
*   **Frame Classifier**: A Linear layer maps the 256-dimensional GRU outputs to 8 class logits followed by Sigmoid activations, yielding independent frame-level probabilities to support overlapping calls.
*   **Unsupervised Domain Adaptation (DANN)**: A secondary Domain Classifier branch is attached to the CNN features via a **Gradient Reversal Layer (GRL)**. The Gradient Reversal Layer encourages the feature extractor to learn representations that are less discriminative of the source and target domains. The effectiveness of this alignment is evaluated indirectly through downstream detection performance, although successful domain invariance has not been independently established.

```
Input: (B, 1, 129, 118)
  │
  ▼
Conv2D + MaxPool2d(2, 1) x 5
  │
  ▼
Reshape & Permute: (B, 118, 1024)
  │
  ▼
Bidirectional GRU
  │
  ▼
Linear + Sigmoid
  │
  ▼
Output: (B, 118, 8)
```

### 2.3 Handling Class Imbalance
Whale calls occupy less than 10% of the recordings. To build a robust model without generating excessive false positives:
1. **Balanced Clip Extraction**: For positive classes, 30-second clips are extracted centered around each ground-truth annotation.
2. **Negative Mining**: For negative classes, unannotated segments of WAV files are identified using a vectorized gap finder and sampled at a 1:1 ratio with positive clips. This balances active and silent clips.

### 3.3 Event Matching Protocol and Metric Definitions
Evaluation is performed at the discrete sound-event level using one-to-one bipartite matching:
1. **Temporal IoU Calculation**: For a ground-truth interval $[t_{\text{start}}^{\text{gt}}, t_{\text{end}}^{\text{gt}}]$ and a predicted interval $[t_{\text{start}}^{\text{pred}}, t_{\text{end}}^{\text{pred}}]$, temporal Intersection-over-Union is:
   $$\text{IoU} = \frac{\max(0, \min(t_{\text{end}}^{\text{gt}}, t_{\text{end}}^{\text{pred}}) - \max(t_{\text{start}}^{\text{gt}}, t_{\text{start}}^{\text{pred}}))}{\max(t_{\text{end}}^{\text{gt}}, t_{\text{end}}^{\text{pred}}) - \min(t_{\text{start}}^{\text{gt}}, t_{\text{start}}^{\text{pred}})}$$
2. **Strict One-to-One Bipartite Matching Implementation**: To prevent a single ground-truth event from matching multiple predictions (or multiple predictions claiming one ground-truth event), matching is solved using `scipy.optimize.linear_sum_assignment` (Hungarian algorithm):
   - **Cost Matrix Construction**: For $N_{\text{gt}}$ reference events and $N_{\text{pred}}$ predictions, a cost matrix $C \in \mathbb{R}^{N_{\text{gt}} \times N_{\text{pred}}}$ is initialized to a large positive penalty ($C_{i,j} = 10^9$).
   - **Valid Edge Bonus**: For each candidate pair $(i, j)$ with $\text{IoU}(i, j) \ge \text{threshold}$, the edge weight is set to $C_{i,j} = -(10^4 + \text{IoU}(i, j))$.
   - **Maximum-Cardinality Guarantee**: The Hungarian solver minimizes the total assignment cost across $\min(N_{\text{gt}}, N_{\text{pred}})$ assigned pairs. Invalid pairs carry a penalty of $+10^9$, whereas valid pairs carry negative costs of $-(10^4 + \text{IoU})$. Consequently, replacing an invalid assignment with a valid assignment produces an overwhelming reduction in total cost ($\approx 10^9$), ensuring that the solver prioritizes the maximum number of valid matches. The constant $10^4$ bonus cancels across assignments with equal numbers of valid matches, allowing the secondary IoU term to select the assignment with the greatest cumulative temporal overlap.
   - **Invalid Pairs & Unmatched Assignments**: After solving the assignment, matched index pairs $(r, c)$ are accepted as True Positives ($TP$) if and only if $C_{r, c} < 0.0$ (i.e. $\text{IoU} \ge \text{threshold}$). Any assigned pair with $C_{r, c} = 10^9$ indicates an unavoidable assignment of mutually exclusive, non-overlapping intervals and is rejected.
   - **Direct Accounting**: False Positives and False Negatives are calculated directly as $FP = N_{\text{pred}} - TP$ and $FN = N_{\text{gt}} - TP$, requiring no dummy nodes.
   - **Empirical Validation of Bipartite Matching Edge Cases**: The implementation was audited against six synthetic test cases to confirm exact match counts under competing and asymmetric geometries:
     1. *One GT overlapping two predictions* (GT: $[0, 10]$, Preds: $[0, 5], [5, 10]$): Correctly assigns $TP = 1$, $FP = 1$, $FN = 0$.
     2. *Two GTs overlapping one prediction* (GTs: $[0, 5], [5, 10]$, Pred: $[0, 10]$): Correctly assigns $TP = 1$, $FP = 0$, $FN = 1$.
     3. *Disjoint intervals (zero overlap)* (GT: $[0, 5]$, Pred: $[10, 15]$): Correctly assigns $TP = 0$, $FP = 1$, $FN = 1$.
     4. *Rectangular matrix with $N_{\text{pred}} > N_{\text{gt}}$* (1 GT, 3 Preds, only 1 overlapping): Correctly assigns $TP = 1$, $FP = 2$, $FN = 0$.
     5. *Rectangular matrix with $N_{\text{gt}} > N_{\text{pred}}$* (3 GTs, 1 Pred, only 1 overlapping): Correctly assigns $TP = 1$, $FP = 0$, $FN = 2$.
     6. *Competitive matching where greedy IoU is suboptimal*: $GT_1$ matches $Pred_1$ ($\text{IoU}=0.8$) and $Pred_2$ ($\text{IoU}=0.1$); $GT_2$ matches only $Pred_1$ ($\text{IoU}=0.75$). Greedy assignment on maximum IoU selects $(GT_1, Pred_1)$, leaving $GT_2$ unmatched ($TP = 1$). Our Hungarian implementation selects $(GT_1, Pred_2)$ and $(GT_2, Pred_1)$ because $2 \times 10^4 + 0.85 > 10^4 + 0.8$, successfully yielding $TP = 2$, $FP = 0$, $FN = 0$.
3. **Threshold Selection Timing & Justification**: The $\text{IoU} \ge 0.1$ threshold was pre-specified in the project codebase from the initial implementation (commit `eee7654`) prior to running final held-out test evaluations. It was selected to capture event overlap while accommodating the acoustic boundary variance inherent in low-frequency marine hydrophone recordings (where multipath propagation, reverberation, and dispersion create diffuse start/end transitions). Because bioacoustic annotation protocols vary in boundary precision across human annotators, $\text{IoU} \ge 0.1$ is employed as our primary pre-specified benchmark to avoid penalizing well-aligned detections that differ only slightly in temporal margin.
4. **Descriptive Sensitivity Across IoU Thresholds**: To evaluate whether comparative conclusions depend heavily on the $\text{IoU} \ge 0.1$ threshold, matching was evaluated across candidate thresholds $\text{IoU} \in \{0.1, 0.3, 0.5\}$:
   - **At $\text{IoU} \ge 0.1$**: CRNN Baseline achieves Macro-F1 = 0.0081 (TP = 8, FP = 933, FN = 379); CRNN DANN achieves Macro-F1 = 0.0203 (TP = 99, FP = 1558, FN = 288).
   - **At $\text{IoU} \ge 0.3$**: CRNN Baseline achieves Macro-F1 = 0.0028 (TP = 3, FP = 938, FN = 384); CRNN DANN achieves Macro-F1 = 0.0055 (TP = 24, FP = 1633, FN = 363).
   - **At $\text{IoU} \ge 0.5$**: CRNN Baseline achieves Macro-F1 = 0.0028 (TP = 3, FP = 938, FN = 384); CRNN DANN achieves Macro-F1 = 0.0033 (TP = 9, FP = 1648, FN = 378).
   *Note on inferential scope*: The IoU sensitivity analysis is descriptive. Paired bootstrap confidence intervals and inferential comparisons are reported for the primary IoU threshold of 0.1 only. The higher macro-F1 values observed for DANN at IoU thresholds of 0.3 and 0.5 should not be interpreted as independently established statistically significant differences. Under all three IoU thresholds, both models exhibit performance collapse at stricter temporal overlap constraints due to coarse windowing and probability floor effects.
5. **Error Accounting**: Unmatched predictions are tallied as False Positives ($FP$); unmatched reference events are tallied as False Negatives ($FN$). Precision, Recall, and F1 are computed per class. Macro-averages are computed over all 8 classes; classes with zero reference events in the test set or zero predictions yield $F_1 = 0.0$ and are retained in the macro-average.

## 4. Methodological Analysis & Limitations

### 4.1 Evaluation Protocol Scope and Dataset Limitations
While the partition protocol strictly eliminated data leakage between adaptation, validation, and testing within the available datasets, several critical experimental constraints remain:
1. **Single Target Deployment**: All target-domain recordings originate from the Greenwich 2015 deployment. Generalisation to independent geographic sites, different hydrophone mooring depths, and future deployment seasons remains unverified.
2. **Target Data Exposure**: The DANN model receives 95 unlabelled recordings from Greenwich 2015 during training for adversarial domain adaptation. It does not represent zero-shot cross-site transfer.
3. **Target Validation Reliance**: Threshold calibration and validation checkpointing rely on a separate labelled subset (38 recordings) from the same target deployment.
4. **Held-Out Integrity**: The final 57 test recordings remained strictly held out and untouched until final evaluation.
5. **Class Imbalance and Sparse Event Support**: The held-out evaluation set contains only 387 reference events across eight classes, with extreme support imbalance: Antarctic Blue Whale calls (`Bm.Ant-A`) account for 246 events (63.6%), while Fin Whale pulse types (`Bp.20Hz` and `Bp.20Plus`) are represented by just a single ground-truth event each. Performance estimates and bootstrap intervals for rare classes are inherently unstable and must be interpreted with caution.

### 4.2 Adversarial Domain Adaptation and Ablation Limitations
In logged training epochs, the domain classification loss remained near $\ln 2 \approx 0.694$ (chance level). Without an otherwise identical CRNN baseline trained strictly without the Gradient Reversal Layer under identical training schedules, random seeds, and hyperparameters, the observed performance difference cannot be attributed exclusively to the Gradient Reversal Layer. Potential confounding factors include stochastic optimization trajectories and differing sensitivity to class imbalance.

### 4.3 Sensitivity to Detection Thresholds and Probability Floors
Under standard 0.5 decision thresholds, event recall collapses because raw frame probability outputs remain predominantly low ($<0.20$). While event-level threshold calibration on validation data identified active operating points for prominent call types, low candidate thresholds (e.g. 0.05) are vulnerable to background probability floors, creating extended continuous activations. Future work should investigate temperature scaling, logit calibration, and adaptive dynamic thresholding conditioned on local ambient noise levels.

## 5. Future Research Directions

### 5.1 Model and Training Improvements
1. **Controlled GRL Ablation**: Execute a systematic ablation comparing: (a) CRNN trained solely on source data, (b) CRNN trained with both source and unlabelled target data but without GRL, and (c) CRNN-DANN with GRL under matched seeds and learning rate schedules.
2. **Hyperparameter Sensitivity & Convergence**: Conduct grid sweeps across GRL trade-off parameter schedules ($\lambda_{\text{max}} \in [0.1, 1.0]$), GRU layer depth, and dropout rates under extended training budgets with patience-based early stopping.
3. **Class-Specific Focal Loss Optimization**: Optimize class-dependent focusing parameters ($\gamma_c, \alpha_c$) to counteract the dominance of high-support classes (`Bm.Ant-A`) over extremely rare call types (`Bp.20Plus`).

### 5.2 Detection and Post-Processing Calibration
1. **Probability Calibration**: Implement temperature scaling and Platt scaling on validation logit outputs to suppress the background probability floor.
2. **Ambient Noise-Adaptive Thresholding**: Dynamically condition detection thresholds on local signal-to-noise ratios (SNR) computed from flanking silence intervals.
3. **Temporal Post-Processing Sensitivity**: Systematically evaluate the sensitivity of detection boundaries to median filter width, minimum event duration thresholds, and maximum bridging gaps for fragmented calls.

### 5.3 Generalization Across Geographic Sites
1. **Independent Multi-Site Benchmarking**: Evaluate models on unadapted acoustic archives from disparate oceanic basins (e.g., Kerguelen Plateau, Ross Sea).
2. **Cross-Year Robustness**: Assess performance drift across multi-year temporal deployments under changing ice-cover dynamics and shipping noise variations.
